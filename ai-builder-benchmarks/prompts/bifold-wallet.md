# Bifold Wallet

Create a bifold wallet template with a main shell and two internal card pocket pieces.

Requirements:

- AI Builder JSON only.
- Units in millimeters.
- Include a wide outer shell pattern piece with a centered vertical fold line.
- Include left and right pocket pattern pieces.
- Use rectangular cut boundaries for all pieces.
- Include seam allowances for the shell and pockets.
- Add stitch paths around pocket sides/bottom and the shell perimeter where sewing is expected.
- Add seam connections where pocket edges sew to matching shell edge spans.
- Use hardware only if it is useful; do not add decorative geometry.
- Use stable snake_case IDs and mark-line text labels.
- Keep dimensions practical: shell around 220 mm wide by 90 mm tall, pockets around 95 mm wide by 64 mm tall.

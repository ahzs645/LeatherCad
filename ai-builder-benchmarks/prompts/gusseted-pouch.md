# Gusseted Pouch

Create a gusseted pouch template with front/back panels and one gusset strip.

Requirements:

- AI Builder JSON only.
- Units in millimeters.
- Include closed pattern pieces for front panel, back panel, and gusset strip.
- Use rectangular cut boundaries so each pattern piece compiles to a closed outline.
- Include seam allowances on every piece.
- Include stitch paths on panel side/bottom edges and along the gusset edges.
- Add seam connections between panel edges and matching gusset spans; use edge spans when needed so lengths match within tolerance.
- Include mark-line text labels for each piece.
- Keep dimensions practical: panels around 120 mm wide by 95 mm tall, gusset around 35 mm wide with enough length to wrap the sides and bottom.
- Use stable snake_case IDs.

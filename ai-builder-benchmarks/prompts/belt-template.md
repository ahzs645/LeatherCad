# Belt Template

Create a belt strap template with keeper/buckle-end markings and punch locations.

Requirements:

- AI Builder JSON only.
- Units in millimeters.
- Include one long closed belt strap pattern piece.
- Use a rectangular cut boundary for export readiness.
- Include a seam allowance or edge finishing allowance entity for the strap.
- Add stitch paths or mark lines along both long edges.
- Add hardware markers for buckle rivets and adjustment holes.
- Include guide or mark lines for keeper placement and buckle fold-back.
- Use practical dimensions: about 900-1100 mm long and 35-40 mm wide.
- Use stable snake_case IDs and mark-line text labels.

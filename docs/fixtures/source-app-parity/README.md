# Source-App Parity Fixtures

This folder records fixtures derived from the reverse-engineering bundle at
`/Users/ahmadjalil/Downloads/leather-making`.

The current bundle contains action catalogs, form resources, Ghidra exports, and
the desktop app binary, but it does not contain user-authored `.lcc` or `.ctlg`
documents. Add real desktop-generated files here when available so importer,
exporter, and parity tests can exercise actual source-app payloads.

Seeded assets and generated fixtures:

- `public/assets/source-app/backImage.tiff`: legacy source-app raster background
  fixture from `.resource/backImage.tiff`.
- `generator-golden/*.lcc`: reproducible LeatherCad-generated golden outputs
  for watch band, pass case, box joint, jigsaw, dice cup, cap pattern, and
  letter stamp workflows. These protect importer/exporter and generator
  behavior, but they are not substitutes for files generated by the native
  desktop app.
- `source-app-parity-manifest.json`: checklist of fixture classes that still
  need real desktop/user samples.

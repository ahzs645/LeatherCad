# Digital calibration regression fixtures

These files intentionally apply 110% portrait X and 90% portrait Y calibration, including the landscape axis exchange. They verify coordinate scale and shared tile overlap in browsers and an independent PDF reader. **Use the parent directory's 100% sheets for physical printer calibration.** Labels inside these automated drawings state nominal model dimensions; their printed physical lengths deliberately include the stated calibration.

All shapes and labels are synthetic, generated by `scripts/generate-print-calibration.mjs` through LeatherCad's print pipeline. No captured or user artwork is included. Physical printer measurements remain pending.
